# Technical Document Cleaner Skill


## Rol

Especialista en preparación de datos para sistemas RAG.


## Objetivo

Convertir documentos técnicos desordenados en texto limpio y útil.


## Problemas a detectar


- Encabezados repetidos.
- Pies de página.
- Texto duplicado.
- Caracteres corruptos.
- Errores OCR.
- Separación incorrecta de tablas.


## Proceso


Paso 1:

Detectar ruido documental.


Paso 2:

Eliminar elementos repetitivos.


Paso 3:

Mantener:

- Valores eléctricos.
- Tablas.
- Fórmulas.
- Nombres técnicos.


Paso 4:

Normalizar formato.


## Nunca eliminar:


- Unidades.
- Rangos.
- Advertencias.
- Condiciones máximas.


## Resultado esperado:


Documento limpio preparado para embeddings.

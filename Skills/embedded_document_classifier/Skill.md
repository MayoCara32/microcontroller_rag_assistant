# Embedded Document Classifier Skill


## Rol

Actúa como arquitecto de información especializado en documentación de sistemas embebidos.


## Objetivo

Clasificar documentos técnicos para mejorar la recuperación dentro del sistema RAG.


## Categorías principales


Microcontroladores:

- Arduino
- ESP32
- Raspberry Pi Pico
- STM32


Protocolos:

- UART
- SPI
- I2C
- CAN
- Modbus


Electrónica:

- ADC
- DAC
- PWM
- Timers
- Interrupts


Drivers:

- Motores
- Sensores
- Displays


## Proceso


Analizar:

1. Nombre del archivo.

2. Contenido.

3. Palabras clave.

4. Fabricante.

5. Dispositivo.

# RAG Chunk Optimizer Skill


## Rol

Especialista en preparación de información para recuperación semántica.


## Objetivo

Determinar cómo dividir documentos técnicos para obtener fragmentos útiles.


## Principios


Un chunk debe contener:

- Una idea completa.
- Contexto suficiente.
- Información relacionada.


## Evitar:


Chunks demasiado grandes:

Problema:

- Mucho ruido.
- Baja precisión.


Chunks demasiado pequeños:

Problema:

- Pierden contexto.


## Analizar:


- Secciones.
- Títulos.
- Tablas.
- Ejemplos.


## Para documentos técnicos:


Priorizar separar:

- Configuración.
- Características eléctricas.
- Pines.
- Ejemplos.
